# Contributing to skillspec

Thank you for your interest in improving the AI Agent Skill Specification (`skillspec`)!

## Specification Guidelines

1. **Format Standards**:
   - All schemas must follow valid JSON Schema Draft-07 conventions.
   - Schema files are located in `schemas/`.
   - Avoid breaking changes without a major version increment.

2. **Testing & Validation**:
   - Validate JSON schemas against standard test fixtures before submitting changes.
   - Ensure test manifests pass validation.

3. **Submitting Changes**:
   - Propose changes via Pull Requests against `main`.
   - Provide explicit architectural justification in the PR description.
