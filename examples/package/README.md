# gitlab-policy-reviewer

A skill for AI agents that reviews GitLab security policies and merge request approval policy YAML for compliance and correctness.

## Compatibility

| Platform | Supported |
|---|---|
| Codex | Yes |
| GitLab Duo | Yes |
| Claude Code | Yes |

## Usage

Install via `skpm`:

```
skpm add default/gitlab-policy-reviewer
```

Then invoke in your agent session by referencing the skill or letting the agent discover it from the platform output.

## Requirements

- No network access required
- No secrets required
- No file writes
